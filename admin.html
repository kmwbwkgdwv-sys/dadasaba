管理ページ

プレイヤーIDを指定して、コインやチケットをプレゼントボックスに送れます。
このページはゲームの中には出てきません。管理者のプレイヤーIDとパスワードがないと何もできません。

1. 管理者としてログイン

（このブラウザでゲームを遊んでいるアカウント を使います）

別のアカウントで入るときは下に入力：

2. はじめての設定（1回だけ）

ログインすると確認できます

あなたの UID：

  1. 下の「ルールをコピー」を押す（あなたの UID が入ったルールです）
  2. Firebase コンソール → Realtime Database → ルール タブ
  3. 前のルールを 全部消して 貼り付け → 公開
  4. このページで「もう一度確認」を押す

3. プレゼントを送る

→ 全てのプレイヤーに送ります

送るもの（送りたいものだけ数を入れる。空や0は送りません）

送り先のプレイヤーIDが合っているかは、こちらでは確かめられません。間違えると届きません。
相手がゲームを開くと（数分以内に）プレゼントボックスに届きます。
全てのプレイヤーに送ったものは、引き継ぎコードを発行している人のプレゼントボックスに届きます（1人1回）。

4. 送ったプレゼントを見る・取り消す

プレイヤーIDを入れて「見る」→ その人に送ったもの。空のまま「見る」→ 全てのプレイヤーに送ったもの（受け取った人数も出ます）。
1人に送ったものは、まだ受け取っていないときだけ取り消せます。全員へのものを取り消すと、まだ受け取っていない人には届かなくなります。
